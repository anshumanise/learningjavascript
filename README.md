# JavaScript Learning Exercises

This repository contains JavaScript exercises and examples for learning fundamental concepts like functions, arrays, and more. Perfect for beginners to watch, learn, and grow their skills!

## Files Overview

- `cofeedistributor.js`: Calculates order totals with discounts using `map` and `reduce`.
- `findandfindindex.js`: Examples of `find` and `findIndex` methods.
- `functionIntro.js`: Introduction to pure functions.
- `index.html`: HTML file to run scripts in the browser.
- `mappfunc.js`: Demonstrates the `map` function.
- `redusefunc.js`: Examples of the `reduce` function.
- `scaffold.js`: Currying example.
- `thispinter.js`: Basics of the `this` keyword.

## How to Use

1. Clone the repo: `git clone https://github.com/anshumanise/learningjavascript.git`
2. Open in VS Code or your editor.
3. Run scripts via `index.html` in a browser or Node.js.

Feel free to fork, contribute, or use for learning!
